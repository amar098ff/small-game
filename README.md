> A fast-paced reaction game built with React. Click the glowing dot before it disappears — beat your best time!

---

## 🎮 How to Play

1. Press **▶ Start**
2. Wait for the glowing dot to appear anywhere in the arena
3. **Click it as fast as you can!**
4. The dot disappears after **1.8 seconds** — don't miss!
5. You have **15 seconds** — score as many hits as possible

---

## ✨ Features

- **⚡ Real-time reaction tracking** — see your speed in milliseconds
- **💥 Particle burst animations** on every hit
- **⏱️ 15-second countdown** with danger alert when time is low
- **🏆 Best reaction time** tracker per session
- **🎯 Miss counter** — clicking outside the dot counts as a miss
- **🌙 Dark premium UI** with smooth animations

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-username/dot-dash.git

# Navigate to project
cd dot-dash

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173
```
